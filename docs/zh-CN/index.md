# ok-nte 文档

ok-nte 是一款面向《异环》的 Windows 自动化工具。它通过截图识别、OCR、系统音频反馈和常规键鼠输入与游戏交互；不读取游戏内存，也不修改游戏文件。

## 开始使用

- [安装](getting-started/installation.md)：下载发行版或从源码启动项目。
- [使用前配置](getting-started/configuration.md)：确认分辨率、画面、按键和窗口状态。
- [快速上手](guides/quick-start.md)：启动一个任务并安全停止。

- [开发文档](../development/running-from-source.md)：准备本地环境、运行和验证改动。

!!! warning "使用风险"
    本项目是外部辅助工具，仅供学习与交流。使用第三方工具可能违反游戏规则并带来账号风险；请先阅读游戏官方规则并自行承担全部风险。
