# 快速上手

## 启动任务

1. 按照[使用前配置](../getting-started/configuration.md)检查游戏设置和窗口状态。
2. 启动 ok-nte。
3. 在游戏中进入需要自动化的场景或关卡。
4. 在应用界面选择任务并点击“开始”。

任务开始后，请留意应用日志和游戏画面。识别失败时，先停止任务，确认画面、分辨率和按键设置后再重新开始。

## 命令行启动

可用命令行参数在启动后自动运行指定任务：

```bash
# 启动后执行列表中的第 2 个任务，并在完成后退出
ok-nte.exe -t 2 -e
```

- `-t` 或 `--task`：启动后自动执行任务列表中的第 N 个任务，`1` 表示第一个任务。
- `-e` 或 `--exit`：任务完成后自动退出程序。

!!! warning
    任务编号依赖当前应用的任务列表。使用命令行自动化前，先在界面中确认目标任务的位置。

## 停止与恢复

如果画面与预期不一致、游戏窗口失焦，或需要临时接管操作，请立即在应用中停止任务。恢复前，重新确认场景、窗口和前置条件；不要依赖长时间的重复输入来纠正异常画面。
