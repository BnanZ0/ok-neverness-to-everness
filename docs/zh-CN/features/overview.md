# 功能概览

功能会随版本变化；请以应用内可见任务和最新发行说明为准。

## 日常与周常

- 一键日常：经验与甲硬币、异能升级材料、弧盘突破材料、空幕、一咖舍任务、影院约会和羁遇赠礼。
- 羁遇赠礼：自动完成角色赠礼流程。

## 都市闲趣

- 自动钓鱼和自动鼓组音游。
- 店长特供：循环进出关卡，需配合游戏内的挂机流派。
- 自动粉爪大劫案，以及快速拾取、自动切换角色快速奔跑等便利功能。

## 特定任务与副本

- 九百九十九夜、异象界域、异象追猎和自动小旋风。
- 呗果智能体：在呗果社区中发帖、回帖、点赞，或使用助手模式辅助生成文案。

## 实时触发与战斗

- 自动战斗：基于计算机视觉，并可通过角色中心管理自定义出招表和识别特征。
- 声音驱动：基于游戏音频反馈进行自动闪避和反击。
- 跳过对话与快速传送。

## 娱乐与辅助

- 自动弹琴：分析 MIDI 音轨并完成游戏内钢琴演奏。
